# TamaPoke Pal Assets

Public staging repository for Pal images and generated sprites used as PixelLab references.

The main TamaPoke repository can remain private while PixelLab receives unauthenticated HTTPS image URLs from this repository. Use `front-image-urls.json` for automation and `front-image-urls.md` for inspection.

Preferred PixelLab input per Pal: `pals/<Pal Name>/sprites/front-96.png` as a raw GitHub URL.

Generated index count: 293 Pals with at least one front sprite variant.
